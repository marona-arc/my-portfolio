# Merna Aly — Portfolio Website

A responsive static portfolio website prepared for GitHub Pages.

## Publish it on GitHub Pages
1. Create a **public** GitHub repository named `merna-aly-portfolio` (or any name you prefer).
2. Upload `index.html`, `style.css`, and the `assets` folder to the repository's root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose branch `main` and folder `/(root)`, then click **Save**.
6. Wait a few minutes. Your site URL will look like `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.

## Before publishing
- Check that every project link points to the correct repository.
- Confirm that the email and social links are the ones you want public.
- This is a static website; the PDF is included as an optional view/download link.
